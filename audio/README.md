# Audio-Dateien

## Vitamin-D-Warnung

Lege deine Audiodatei hier ab:

```
audio/vitamin_d_mangel.ogg
```

Unterstützte Formate: **OGG**, **WAV**, **MP3** (Dateiname in Godot importieren lassen).

Der Sound wird abgespielt, wenn die Bevölkerung **Vitamin-D-Mangel** hat — also wenn zu wenig angereicherte Milchprodukte oder Frühstück im Lager sind (Hafermilch, Sojamilch, Sojajoghurt, Frühstück).
