# Gesundheits-Warnsounds

Lege diese Dateien in diesen Ordner (`res://audio/`):

| Datei | Marker |
|-------|--------|
| `b12_mangel.ogg` | Vitamin B12 Mangel |
| `vitamin_d_mangel.ogg` | Vitamin D Mangel |
| `mental_mangel.ogg` | Mentale Gesundheit Mangel |

Formate: `.ogg`, `.wav` oder `.mp3`

Die Pfade kannst du im Inspector unter dem Autoload **PopulationHealth** anpassen.

Sounds werden abgespielt, wenn ein Mangel besteht — höchstens alle **3 Spieltage** pro Marker.
