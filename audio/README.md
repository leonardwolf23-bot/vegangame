# Audio-Dateien

Warnsounds für Bevölkerungsmangel — jeweils höchstens **alle 3 Spieltage** einmal.

| Datei | Alert |
|-------|-------|
| `audio/vitamin_d_mangel.ogg` | Vitamin-D-Mangel |
| `audio/b12_mangel.ogg` | Vitamin-B12-Mangel |
| `audio/protein_mangel.ogg` | Proteinmangel |
| `audio/essen_mangel.ogg` | Essensmangel |

Unterstützte Formate: **OGG**, **WAV**, **MP3**

Pfade ändern: **Project → Project Settings → Autoload → PopulationHealth**

## Was zählt als Versorgung?

- **Vitamin D:** Hafermilch, Sojamilch, Sojajoghurt, Frühstück
- **Vitamin B12:** Angereicherte Milchprodukte, Tofu, Frühstück
- **Protein:** Tofu, Seitan, Hummus, Hülsenfrüchte, Gebäck, Streetfood, …
- **Essen:** Lager-Essen (kg) + fertige Mahlzeiten (Brötchen, Pommes, Salat, …)
